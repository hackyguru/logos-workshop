# Persona has moved

The Persona wallet (formerly "Logos Wallet") — the `persona_core` base-chain
node/LEZ module and the `persona` QML UI — now lives in its own repository:

**https://github.com/hackyguru/persona** (`core/` + `ui/`)

It is published to the catalog at https://modules.hackyguru.com. Development no
longer happens in this monorepo; edit the persona repo directly.
